# Turbine Lab learning guide

Turbine Lab is an interactive classroom model of a simple steam Rankine cycle. Change an input and follow the consequences in the power, efficiency, steam state, turbine animation, cycle plots, and energy-flow diagram.

## Start here

1. Open `../index.html` (or the deployed [Turbine Lab simulator](https://turbinelab.aadityahasabnis.com/)).
2. Choose a scenario card, then change one control at a time.
3. Watch electric output and efficiency, then inspect the T–s or P–v plot and Sankey diagram.
4. Use **Compare** to pin a baseline before changing the controls.
5. Read the guide’s [questions and glossary](index.html#learn-more) to connect the observation to the physics.

## Learning objective

Explain how boiler pressure, inlet temperature, mass flow, turbine efficiency, and condenser pressure affect turbine work, electrical output, thermal efficiency, and exhaust moisture. Change one variable at a time and record both the benefit and the trade-off.

> This is an educational approximation. It is not a plant-design calculator, safety model, or operating guide.
